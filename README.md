#  Rock Paper Scissors - Python Game

An interactive command-line Rock Paper Scissors game built using Python.  
This project demonstrates basic game logic, conditional statements, dictionaries, and loop control.

##  Features

- User input validation
- - Random computer choice
- - Win/Lose/Draw detection
- - Restart game functionality
- - Clean and simple CLI interface
       
##  Technologies Used

- Python 3
- - Random module
  
##  How to Run

1. Download the repository
2. Open terminal in project folder
3. Run:  
4.    python game.py

##  Learning Outcomes

- Understanding conditional statements
- - Working with dictionaries
- - Using loops for continuous gameplay
- - Handling user input properly
